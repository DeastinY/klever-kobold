The Klever Kobold

A Pathfinder 2e rules reference that runs on your own computer, cites every answer, and is wrong just often enough to keep you honest.

  • runs fully offline
  • needs 6 GB RAM
  • python 3.11+
  • coverage {{COVERAGE}}
  • vibecoded fully

Install

macOS or Linux

curl -fsSL https://raw.githubusercontent.com/DeastinY/klever-kobold/main/deploy/install.sh | sh

Windows

irm https://raw.githubusercontent.com/DeastinY/klever-kobold/main/deploy/install.ps1 | iex

Already have uv

uv tool install git+https://github.com/DeastinY/klever-kobold
kobold setup --install-ollama
kobold serve

Either way it installs Ollama if missing, pulls two small models (about 4 GB), fetches the index of rules and lore (270 MB), and opens the kobold in your browser at localhost:8765.

What it is

  • The Archives, not a memory. Every answer is read from the Archives of Nethys and PathfinderWiki entries shown underneath it. Nothing you type leaves the machine.
  • Rules and lore, kept apart. A rules question never gets a wiki answer. The kobold reads the question, picks the shelf, and sticks to the rules when unsure.
  • Wrong is a first-class state. Lookups are reliable; "does X interact with Y?" is not, but the right pages are usually on screen. Every answer has a "Wrong? Tell the kobold" link.
